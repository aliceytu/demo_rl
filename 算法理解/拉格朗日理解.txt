一、λ 是什么：约束的价格（影子价格）
--------------------------------------------------------------------------------
打分式（sp32 内层 argmax 用）：
    score = gmv + λ_trip·trip + λ_gp·gp + λ_cr·cr_ecr

λ 的业务身份 = 约束量与目标量之间的兑换率（经济学名字：影子价格）：
  - 违约区（约束低于目标线）：λ = 违约的单位成本，每差 1 单位按 λ 罚
  - 超额区（约束高于目标线）：λ = 单位补贴，每超 1 单位按 λ 奖
  - 解到最优时，λ = 这条约束的真实市价（放松约束 1 单位能换回多少目标）

读线上 λ 列的方法（从此每个数字都会说话）：
  - λGP = 0.0001（钉在地板）→ TR 约束当天不咬人（放松它换不回收益）
  - λCr ≈ 21~23           → CR 约束当天极贵、卡脖子
  - cafune_rl 里的 weight 5.0 = 一个手写死、不再更新的 λ


二、max(min_lambda, λ − step·grad) 的两层含义（sp32_dri.py:895）
--------------------------------------------------------------------------------
这行更新式拆成两部分，各管一件事：

第 1 层：λ − step·grad = 次梯度下降（方向）
  grad = (sum_opt − base·(1+th)) / f = 约束缺口
  ── 只依赖"当前这轮"argmax 出的结果和基准线，与上一轮无关（不是迭代差分！）
  ── 破线（grad<0）→ λ 上升：价格定低了违约才划算，抬价让违约变贵
  ── 超额（grad>0）→ λ 下降：松开价格，把空间还给目标
  闭式梯度的来源 = 包络定理：λ 小邻域内每单选的 sp 不变（x* 冻结），
  对固定表达式求偏导只剩约束项，"x* 怎么随 λ 动"的复杂性自我湮灭。

第 2 层：max(min_lambda, ·) = 投影/地板截断（边界）——纯记账，与求导无关
  ── 把更新后的 λ 拽回 [min_lambda, +∞)
  ── 原因：λ 是价格，负价格 = 违约有奖（每破线一单位倒贴钱），荒谬，截掉


三、对偶的方向：给的是上界，min 是在压薄它
--------------------------------------------------------------------------------
  g(λ) = max over 所有解（包括违约的！）[ gmv + Σλ·(约束−目标) ]
  ── 违约解也参赛、只交罚金（λ×缺口）→ optimizer 自由度只多不少
  ── 所以对任意 λ≥0：g(λ) ≥ 原问题最优 OPT（上界，不是下界！）

  外层对 λ 做 min = 把上界往下压：
  ── V 字形：违约者还在赢的区间，抬 λ → 罚金变重 → max 玩家换人 → g 下降
  ── V 字底部 = 违约者和合规者打平的 λ* = 约束恰好贴线的市场出清价
  ── 常数步长 + V 字地形 = 在底部两侧来回弹 → 这就是震荡、backup 机制、
     各国 step hack 的共同几何根源


四、reward 里的违约价格（cafune_rl，hinge 项，3299）
--------------------------------------------------------------------------------
  v_trip = max(0, TRIP_TH − inc_trip)          ← hinge：只罚缺口，超额无奖
  raw_reward = gmv_lift − 5·v_trip − 5·v_tr − 5·v_cr − 0.1·smooth

  分段价格表（这是"1 个点 trip 换 5 个点 gmv"那笔账的准确定义）：
  ── 低于阈值：每 1pp trip 值 5pp GMV（违约区内的边际兑换率）
  ── 达到阈值：1pp trip 值 0 GMV（缺口消失交易关闭，多一分不花）
  ── 稳态行为 = 贴线走（threshold crawling）

  权重 5 的真实身份 = 约束的买断价（软约束语义）：
  ── 补缺的真实代价 < 5:1 → agent 把约束拉到达标（贴线）
  ── 补缺的真实代价 > 5:1 → agent 选择永久交罚款、住在违约里
  ── 所以权重不是训练技巧，是业务定的违约金费率；
     若线上看到"长期贴着某约束破线小几百个基点"，先查权重是否低于
     该约束的真实市场价格，再查 bug

  与 λ 的血缘：λ 是对偶迭代解出来的价格（自动定价），weight 5 是写死的
  价格（固定定价）——同一个"约束价格"概念的两种供给方式。


五、score 与 reward 的层次关系（别混成同一个东西）
--------------------------------------------------------------------------------
  拉格朗日 score（sp32 和 cafune_rl 环境内部都有）：
    → 决策规则：进 argmax，决定每个冒泡选哪个调价档
  raw_reward（cafune_rl 环境外层）：
    → 评分单：argmax 做完后给本窗口整体打分，作为 RL 的学习信号

  共存于同一条管线（辈分差一级）：
    RL 调 λ → score 选档（每单）→ 窗口指标 → reward 评分（整体）
            → 更新 λ 策略 → 循环

  同构处：都是"目标 + 价格×约束"的标量化；
  差异处：score 价格作用于约束全量（每单位），reward 价格只作用于缺口
  （hinge）；score 的 λ 可学习，reward 的权重写死。

（本节完）
